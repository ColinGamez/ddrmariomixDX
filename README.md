# ddrmariomixDX

**Dance Dance Revolution Mario Mix — revived for PC, with more of everything.**

This is a fan project rebuilding the 2005 GameCube cult classic *DDR Mario Mix*
as a native PC game — and then going beyond it:

- 🎵 **Custom songs** — dance to tracks from other Nintendo games (and more)
- 🌍 **New worlds and game modes**
- 🍄 **More playable characters** from the Mario universe
- 🕹️ **Play with keyboard or a USB dance pad**

## Status: early development 🚧

There's no download yet — we're still rebuilding the game piece by piece.
So far we've fully cracked the game's chart, model, and music formats, which
means custom content is genuinely possible, not just a dream. Follow the repo
for updates; releases will be posted here when there's something playable.

## FAQ

**Will I need the original game?**
Yes. To stay legal, the final game will pull its music, characters, and stages
from *your own* copy of the GameCube disc (or your legally dumped ISO).
Nothing from the game is distributed here — ever.

**Will it work with my dance pad?**
That's the plan — the goal is plug-and-play USB pad support on PC, plus
keyboard play.

**Is this an emulator/ROM hack?**
No. It's a from-scratch rebuild of the game engine for PC. No Dolphin, no
ISO patching — a real port.

**Will it be free?**
Yes, always. This is a non-commercial fan project. Nintendo owns Mario and
DDR Mario Mix; we're just fans keeping a great game alive.

**When is it out?**
When it's fun. It's a hobby project — but every file format standing between
us and a playable build is already cracked, so progress is steady.
